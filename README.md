# 🖥️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Ansh-vibe/software-engineer-portfolio-website.git
```

Navigate into the project:

```bash
cd software-engineer-portfolio-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# 🚀 Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

---

# 🔐 Environment Variables

If environment variables are required, create:

```text
.env.local
```

Example:

```env
NEXT_PUBLIC_API_URL=
NEXT_PUBLIC_SITE_URL=
```

> Never commit sensitive credentials, API keys or private environment variables to GitHub.
